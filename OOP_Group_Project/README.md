# OOP Group Project - Ticket Machine

This project is a ticket machine application written in Kotlin. It is a group project for the Object-Oriented Design module (QHO543) at Solent University.

## Project Structure

The project is structured as follows:

- `src/`: Contains the source code for the application.
  - `Main.kt`: The main entry point for the application.
  - `User.kt`: A base class for users.
  - `AdminUser.kt`: A subclass of `User` for administrators.
  - `Authentication.kt`: A class for handling user authentication.
  - `Ticket.kt`: A class representing a ticket.
  - `TicketMachine.kt`: The main class for the ticket machine.
  - `Station.kt`: A class representing a train station.
  - `SpecialOffer.kt`: A class for special offers on tickets.
  - `TicketType.kt`: An enum for the different types of tickets.
- `.gitignore`: A file specifying which files and directories to ignore in Git.
- `OOP_Group_Project.iml`: The project file for IntelliJ IDEA.

## How to Run

To run the application, you can use the `main` function in `src/Main.kt`.
